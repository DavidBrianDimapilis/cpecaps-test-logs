# Mango Seedling Health Classification (`healthy` vs. `unhealthy`) — ResNet-50 Feature Extraction

## 1. Project Overview
This project implements a GPU-accelerated binary image classification pipeline in PyTorch to classify mango leaves/seedlings into two categories: **`healthy`** and **`unhealthy`**.

Using **Transfer Learning (Feature Extraction)** with an ImageNet-pretrained **ResNet-50** backbone (`ResNet50_Weights.DEFAULT`), all convolutional backbone layers are frozen and the final fully connected classification head (`model.fc`) is replaced with a trainable 2-class linear layer (`Linear(2048 -> 2)`, `4,098` trainable parameters).

### Dataset Generalization & Balancing
The dataset is sourced from the [Kaggle Mango Leaf Disease Dataset](https://www.kaggle.com/datasets/aryashah2k/mango-leaf-disease-dataset/data), which originally contains 8 folders (1 `Healthy` class and 7 specific disease classes: *Anthracnose*, *Bacterial Canker*, *Cutting Weevil*, *Die Back*, *Gall Midge*, *Powdery Mildew*, and *Sooty Mould*, with 500 images each).
- All 7 disease folders (3,500 images) are generalized into a single **`unhealthy`** folder and randomly downsampled to **500 images** to match the **500 images** in **`healthy`** (`1,000` balanced images total).
- The balanced dataset is split into **80% Training (`800 images`: `400 healthy`, `400 unhealthy`)** and **20% Testing (`200 images`: `100 healthy`, `100 unhealthy`)**.

## 2. Repository Structure & Filenames

## 3. Data Fields, Table Headers, and Units

### A. Summary Results File (`mango_classification_results.csv`)
Records each training epoch (`Phase = Train`) followed by the final evaluation pass of the best model on the test set (`Phase = Test (Best Model: Epoch 10)`).

| Column Header | Data Field Description | Data Type | Unit / Format |
| :--- | :--- | :--- | :--- |
| `Phase` | Indicates whether the row is a training epoch (`Train`) or the final test evaluation (`Test (Best Model: Epoch X)`). | String | Categorical (`Train` / `Test`) |
| `Start Timestamp (ISO-8601)` | Exact local date, time, and UTC offset when the epoch or test evaluation started. | Datetime String | `YYYY-MM-DDTHH:MM:SS+08:00` (ISO-8601) |
| `End Timestamp (ISO-8601)` | Exact local date, time, and UTC offset when the epoch or test evaluation finished. | Datetime String | `YYYY-MM-DDTHH:MM:SS+08:00` (ISO-8601) |
| `Strategy` | Transfer learning method used (`feature_extraction`). | String | Text identifier |
| `Epoch / Model` | Current training epoch (`Epoch X / 10`) or the evaluated checkpoint (`Best Model (Epoch 10)`). | String | `count / total` |
| `Total Samples (images)` | Total number of images processed in that phase (`800` for Train, `200` for Test). | Integer + Unit | `images` (count) |
| `Healthy Samples (images)` | Number of `healthy` class images in that split (`400` for Train, `100` for Test). | Integer + Unit | `images` (count) |
| `Unhealthy Samples (images)` | Number of `unhealthy` class images in that split (`400` for Train, `100` for Test). | Integer + Unit | `images` (count) |
| `Learning Rate` | Step size used by the `AdamW` optimizer (`0.001`). | Float | Dimensionless scalar (`1e-3`) |
| `Trainable Parameters (params)` | Number of unfrozen parameters updated during backpropagation (`4098 params`). | Integer + Unit | `params` (parameter count) |
| `Cross-Entropy Loss (loss)` | Average `nn.CrossEntropyLoss` across all samples in the split. | Float | `loss` (nats, 4 decimal places) |
| `Classification Accuracy (%)` | Percentage of images classified into the correct category. | Float + Unit | `%` (percentage, `0.00%` – `100.00%`) |
| `Macro-F1 (score)` | Unweighted mean of the F1-scores across `healthy` and `unhealthy` classes. | Float | `score` (unitless ratio `0.0000` – `1.0000`) |
| `Duration (s)` | Wall-clock GPU execution time (synchronized via `torch.cuda.synchronize()`) for the epoch or test run. | Float + Unit | `s` (seconds) |
| `Device` | Hardware accelerator used for computation (`NVIDIA GeForce RTX 3070 Ti (cuda)`). | String | Hardware name + PyTorch device |

### B. Per-Image Test Predictions File (`mango_best_model_test_predictions.csv`)
Records the individual test prediction for each of the 200 unseen test images using the best model checkpoint.

| Column Header | Data Field Description | Data Type | Unit / Format |
| :--- | :--- | :--- | :--- |
| `Test Timestamp (ISO-8601)` | Exact local timestamp when the test batch containing the image was evaluated. | Datetime String | `YYYY-MM-DDTHH:MM:SS+08:00` (ISO-8601) |
| `Best Model Used` | Identifier of the best epoch checkpoint used for inference (e.g., `Epoch 10`). | String | `Epoch N` |
| `Image Filename` | Filename of the evaluated test image (disease-prefixed for unhealthy samples, e.g., `Anthracnose__...jpg`). | String | `.jpg` filename |
| `True Class` | Ground-truth folder label of the image (`healthy` or `unhealthy`). | String | Class label (`healthy` / `unhealthy`) |
| `Predicted Class` | Class predicted by the ResNet-50 feature extraction model (`healthy` or `unhealthy`). | String | Class label (`healthy` / `unhealthy`) |
| `Correct Prediction (bool)` | Whether `Predicted Class` matches `True Class` (`True` or `False`). | Boolean | `True` / `False` |
| `Confidence (%)` | Softmax probability assigned to the predicted class. | Float + Unit | `%` (percentage, `0.00%` – `100.00%`) |
| `Inference Time (ms)` | Average GPU forward-pass latency per image within the batch. | Float + Unit | `ms` (milliseconds) |
| `Device` | GPU device used during testing (`NVIDIA GeForce RTX 3070 Ti (cuda)`). | String | Hardware name + PyTorch device |

## 4. Instructions for Running the Application

### Prerequisites
1. **Python 3.10+** and an **NVIDIA CUDA-capable GPU**.
2. Install the required Python libraries (with CUDA-enabled PyTorch):
   ```powershell
   pip install numpy matplotlib
   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
   ```

### Dataset Setup
Ensure the `./data` folder is in the project root directory:
- **If you Already Have the Balanced Folders:**
  - `./data/healthy/` (500 images)
  - `./data/unhealthy/` (500 images)
- **If Using the Raw Kaggle Archive:**
  - Extract the 8 folders (`Healthy`, `Anthracnose`, `Bacterial Canker`, `Cutting Weevil`, `Die Back`, `Gall Midge`, `Powdery Mildew`, `Sooty Mould`) into `./data/`. When `class_act3.py` runs, `prepare_balanced_mango_dataset()` will automatically merge the 7 disease folders into `./data/unhealthy/` and randomly remove excess images so `healthy` and `unhealthy` have equal counts (500 each).

### Running the Script
Run `class_act3.py` from the terminal:
```powershell
python class_act3.py
```

### Generated Outputs
Upon completion, the application prints per-epoch progress and test metrics to the console and automatically generates/updates:
1. `best_mango_resnet50_model.pth` — Saved PyTorch weights and configuration of the best epoch.
2. `best_model_config.json` — JSON summary of the best model's configuration and performance.
3. `mango_classification_results.csv` — Epoch-by-epoch training log + best model testing summary row with timestamps and units.
4. `mango_best_model_test_predictions.csv` — Per-image test predictions, confidences (`%`), and inference times (`ms`).
